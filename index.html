THE PROBLEM

Departments respond alone, and gaps cost time

No shared visibility

Traffic police don't know an ambulance is approaching until it's already stuck at a red light.

Blind hospital routing

Patients get sent to the nearest hospital, not the one with an open bed or ICU capacity.

Manual coordination

During floods or mass-casualty events, departments still coordinate by phone calls.

THE IDEA

One coordination layer, not one traffic app

Automatic routing

An emergency reported in any department instantly notifies every other department that needs to know.

Departments keep control

Each department keeps full ownership of its own tools and data — nobody hands over control.

Citizens see only what matters

Public users get the minimum information relevant to their safety, never internal operations.

HOW ROUTING WORKS

Each emergency type has a fixed subscriber list

Emergency typeAutomatically notified
Medical emergencyTraffic Police, Health, Hospitals
FireFire & Rescue, Traffic, Police, Hospitals
Major road accidentPolice, Traffic, Fire, Health, Hospitals
Flood / structuralDisaster Mgmt, Municipal, Fire, Police, Hospitals
Mass casualty eventEvery department

This is a publish–subscribe model — each department subscribes to categories relevant to it, and routing runs without a single phone call.

ACCESS CONTROL

Three tiers decide who sees what

Command centre

  • Sees every active incident
  • Orchestrates routing only
  • Cannot edit dept. systems

Department centre

  • Full access to own tools
  • Read-only view of others
  • Edits nothing outside scope

Citizens

  • Plain-language alerts only
  • Public status: closures, ETA
  • No internal data, ever
TECHNICAL APPROACH

Three mechanisms do the real work

Routing engine

A rules table maps emergency type to subscriber departments. Production: Kafka or a managed pub-sub queue.

Role-based access

JWT claims carry role and department. Enforced server-side — never trust a UI toggle alone.

Citizen data filtering

A dedicated public API exposes only pre-approved fields, never the same endpoints departments use.
